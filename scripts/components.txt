# MacWave 的运行时组件目录 —— 唯一来源。
#
# 这里列出的每个目录都是「运行时可执行代码」的一部分，于是三件事跟着它走：
#
#   1. 安装树：整目录装进 <base_dir>/，逐文件列在 update_commands.sh 里
#   2. 运行时：lib/wave.py 为每个目录加一条 sys.path
#   3. 测试沙箱：把每个目录拷进临时安装树
#
# 加一个组件只应该改这个文件。仓库里另有 scripts/、docs/、images/ 等目录，它们
# 不参与运行，**不要**加进来：一旦加进来，安装树会多出一堆用户不需要的文件，
# （docs 曾让 4.1.1 的清单混进 __pycache__，用户看到一串 404 才更新完成）。
#
# 顺序即 sys.path 的优先次序（靠前的先命中）。模块名在各组件之间必须唯一。
#
# cli/ 与 config/ 排在 lib/ 之前是有意的：4.4.0 把它们从 lib/ 里搬了出来，
# 升级时旧安装树里还留着 lib/help.py 这类平铺副本，只有新目录先命中才不会被
# 旧文件盖住（生成的 update_commands.sh 也会删掉那些副本，这里是第二道保险）。
